# 蜡染AI创作工坊 · BatikScript

> 基于蜡染非遗技法语言开发的 **语法驱动 AI 创作工具**：上传蜡染素材 → 用自然语言描述效果 → AI 生成 BatikScript 语法代码 → 画布实时渲染蜡染效果。
>
> 核心理念：**语法即非遗**。BatikScript 的每一个关键字都来自真实蜡染工艺（画蜡、点蜡、浸染、冰裂、晕染……），AI 帮你把想法翻译成代码，你也可以零成本手动修改代码，精确控制每一层蜡染效果。

---

## ✨ 功能特性

- **双栏创作界面**：左栏 AI 对话 + 三选项卡语法面板（语法手册 / 当前代码 / 历史版本），右栏画布 + 工具栏 + 动态播放控制
- **AI 对话生成代码**：内置 BatikScript 语法引擎，自然语言指令 → 语法代码 → 画布实时同步，每次回复附带对应蜡染工艺知识
- **BatikScript 语法体系**：12+ 条全中文指令，完全对应传统工艺环节，简洁易读、零基础可改
- **图片素材**：支持上传 1-3 张 PNG/JPG，内置 2 张传统蜡染示例图案一键加载
- **蜡染效果引擎**（Canvas 程序化渲染）：
  - 冰裂纹（程序化噪声生成，粗细 / 密度可调）
  - 浸染深度（像素级靛蓝色映射，0-100）
  - 晕染程度（染料渗透过渡）
  - 画蜡笔触 / 点蜡密度（铜刀笔触与点蜡肌理）
  - 透明度 / 旋转 / 位置 / 大小
- **多图融合**：叠印 / 拼接 / 螺旋 / 交织 四种融合模式
- **动态效果**：浸染渐变、冰裂蔓延、图案融合三种动画，支持播放 / 暂停 / 进度拖拽 / 循环 / 任意帧截屏
- **图层交互**：画布拖拽移动、右键菜单（复制 / 删除 / 置顶 / 置底）
- **代码双向同步**：AI 生成代码实时渲染，手动修改代码 Ctrl/⌘+S 或失焦后自动应用，语法错误友好提示
- **历史版本**：自动保存每次变更，一键回退（localStorage 持久化）
- **导出能力**：导出 PNG 作品图、下载 .batik 代码文件、复制代码

## 🚀 使用方法

### 方式一：本地直接打开

直接双击 `index.html`，或用本地静态服务器：

```bash
# 在项目目录下执行
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> 说明：用 `http.server` 打开可以避免部分浏览器对本地文件的限制。

### 方式二：上传 GitHub + GitHub Pages 部署（推荐）

1. **创建仓库**：GitHub → `+` → New repository → 填仓库名（如 `batik-ai-workshop`）→ Public → Create
2. **上传文件**：仓库页 → `uploading an existing file` → 把 `index.html`、`README.md`、`assets/` 文件夹一起拖入 → Commit changes
3. **开启 Pages**：仓库 `Settings` → 左侧 `Pages` → Source 选 `Deploy from a branch` → Branch 选 `main` / `/ (root)` → Save
4. **等待 1-2 分钟**，访问 `https://你的用户名.github.io/batik-ai-workshop/`，任何人打开即可使用

> 所有资源均使用相对路径，部署在子目录下也能正常加载，无需额外配置。

## 📖 BatikScript 语法速查

### 基础图层结构

```
图层[1] {
    素材: "图案A";        // 对应已上传的第 1 张素材
    位置: 100, 200;       // x, y 坐标
    大小: 300, 400;       // 宽, 高
    旋转: 15;             // 旋转角度
}
```

### 蜡染效果指令

| 指令 | 取值范围 | 对应工艺 |
|------|---------|---------|
| `画蜡笔触: 8` | 1-20 | 铜刀画蜡的笔触粗细 |
| `点蜡密度: 60` | 0-100 | 点蜡技法的疏密程度 |
| `浸染深度: 75` | 0-100 | 靛蓝染色深浅（浸染次数） |
| `冰裂纹: 开启` | 开启/关闭 | 蜡染标志性冰纹 |
| `冰裂纹粗细: 4` | 1-10 | 裂纹粗细（蜡层厚度） |
| `冰裂纹密度: 50` | 1-100 | 裂纹分布密度 |
| `晕染程度: 5` | 0-20 | 染料渗透的过渡效果 |
| `融合模式: 叠印` | 叠印/拼接/螺旋/交织 | 多层蜡染组合方式 |
| `透明度: 80` | 0-100 | 蜡层透明程度 |

### 全局配置

```
全局 {
    动画: 浸染;           // 无 / 浸染 / 冰裂蔓延 / 图案融合
    动画速度: 5;          // 1-10
    动画循环: 开启;       // 开启/关闭
    画布底色: 土黄;       // 靛蓝 / 本白 / 土黄
}
```

### AI 常用对话示例

- 「给这张图加冰裂纹，染深一点」
- 「把两张图螺旋融合」
- 「做一个浸染动画」
- 「底色改成靛蓝」
- 「画蜡笔触细一点」

## ⚙️ 技术说明

- **零依赖单文件**：纯 HTML + CSS + JavaScript，无构建步骤、无 npm 依赖，任何静态托管（GitHub Pages / Vercel / Netlify / 任意服务器）都能直接运行
- **AI 对话引擎**：当前版本内置 **BatikScript 规则引擎**（本地运行，无需网络与密钥），严格按语法规范生成代码。如需接入真实大模型 API，可在 `handleIntent` 处替换为 API 调用，把返回的自然语言指令发给模型并约束其输出 BatikScript 代码即可（推荐在提示词中附上本 README 的语法速查作为 few-shot 示例）
- **效果渲染**：冰裂纹、浸染、晕染等均为 Canvas 像素级程序化渲染，严格对应蜡染物理原理，而非简单滤镜
- **数据持久化**：历史版本存储在浏览器 localStorage

## 🧵 文化价值

蜡染古称“蜡缬”，距今 2000 余年，是国家级非物质文化遗产，核心流传于贵州丹寨、安顺、织金等苗族聚居区。本工具将蜡染传统技法体系提炼为可执行的数字语法：

- **技法语言的数字化转译** —— 让无形的非遗技艺拥有标准、可复制、可传播的数字载体
- **低门槛的非遗参与** —— AI 降低使用门槛，简洁语法让用户从 AI 辅助过渡到手动创作
- **创作即传承** —— 每次使用指令、修改代码，都在接触与使用蜡染的专业术语与工艺逻辑
